什么是C 语言?

04-地址与指针

使用内存

C 被设计为一种**低级语言**，可以轻松访问内存位置并执行与内存相关的操作。 例如，scanf()函数通过使用&符号将用户输入的值 举例：

#include <stdio.h>

int main() {
    int num;
    printf("Enter a number:");
    scanf("%d", &num);
    printf("%d", num);
    return 0;
}
